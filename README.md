# ひなた製菓 社内システム「仕入れ請求書の入力」（研修用の練習サイト）

ブラウザ操作の自動化（Claude in Chrome など）を練習するための、**架空の会社の社内システム**です。
Excel の明細を見ながら、仕入れ請求書を1行ずつ入力して登録する画面です。

👉 **https://yudaiishii585.github.io/invoice-entry-test/**

ログインは不要です。URL を開けばすぐ使えます。

> ⚠️ 実在の会社・実在のデータではありません。
> 入力した内容はこのブラウザの中（sessionStorage）にだけ残り、どこにも送られません。

## 練習の流れ

1. 画面右上の「練習用の Excel をダウンロード」から `請求書の明細.xlsx` を取る
2. 仕入先・請求日を入れる
3. 明細を1行ずつ（品名・数量・単価 →［追加］）入れる
4. ［登録する］を押す →「登録しました（6件・合計 ¥86,200）」と出れば正解

練習用の Excel の中身：仕入先 さくら製粉株式会社／請求日 2026年11月20日／明細6行／合計 86,200円（税抜）

## 画面の部品（自動化するときの目印）

| 部品 | id |
|---|---|
| 仕入先 | `supplier` |
| 請求日（日付） | `invoice-date` |
| 品名・数量・単価 | `item-name`・`item-qty`・`item-price` |
| ［追加］ | `add-btn`（Enter キーでも追加） |
| 明細の表 | `lines-table`（行は `line-1`, `line-2`…、削除は `delete-1`…） |
| 合計（税抜） | `total` |
| ［登録する］ | `submit-btn` |
| 登録の結果 | `submit-message` |
| 入力をすべて消す | `clear-btn` |

数量・単価は、全角数字やカンマ（`6,800`）で入れても読めます。

## 中身

静的ファイルだけで動きます。

```
index.html   画面
app.js       明細の追加・削除・合計・登録の表示
style.css
meisai.xlsx  練習用の Excel（ダウンロード時の名前は「請求書の明細.xlsx」）
```
